# Sanjvaat site

Open `index.html` in a browser, or serve this folder with any static web server.

The site uses HTML, CSS and a small JavaScript motion layer. All supplied images are included with the site, and the Instagram links open in a new tab.

Pages:

- `index.html` - Home
- `story.html` - The Sanjvaat tradition and story
- `candles.html` - Candle collection
- `gifting.html` - Gift arrangements
